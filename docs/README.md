# Documentación del repositorio

Esta carpeta reúne decisiones operativas del repositorio de informe, notas de release y futuras instrucciones de exportación. La narrativa académica vive en `report/`.

## Criterios de esta etapa

- El contenido de los capítulos se incorpora de forma incremental.
- Las instrucciones del enunciado del curso se usan como referencia de cobertura; no se copian como contenido del informe.
- Cada cambio relevante debe usar Conventional Commits y conservar una firma verificable.
