# v0.1.0-scaffold

## Alcance

Primera base del repositorio `web-report`.

## Incluye

- Metadatos mínimos del repositorio.
- Estructura modular del informe web.
- Placeholders Markdown para las secciones del índice.
- Carpetas reservadas para assets, evidencias y anexos.

## No incluye

- Redacción académica final.
- Evidencias de implementación o validación.
- Exportación PDF final.
